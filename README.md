# cpd-vitals-annotation
Annotation tool for change points in continuous vital sign recordings.

## About

This repository will contain the custom-developed annotation software used in the study:

> Tjepkema WWA, John A, Ranasinghe C, Breteler MJM. *Unsupervised Multivariate Change Point Detection for Continuous Physiological Monitoring Using Wearable Sensors: A Feasibility Study.* Submitted to BMC Digital Health.

In this study, clinical experts used the tool to annotate change points in 24-hour wearable vital sign recordings (heart rate, respiratory rate, temperature, blood pressure and oxygen saturation) from general ward patients. These annotations served as the reference standard for evaluating an unsupervised, online, multivariate change point detection model.
